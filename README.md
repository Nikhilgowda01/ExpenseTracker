````markdown
# Expense Tracker 💰

A simple **Java console-based Expense Tracker** project.

This project is being developed step-by-step while learning Java programming.

## 📌 Project Overview

The Expense Tracker allows users to manage their expenses through a simple console menu.

Users can:

- Add an expense
- View an expense
- Modify an expense
- Delete an expense
- Exit the application

## 🛠️ Technologies Used

- Java
- VS Code
- Git
- GitHub

```text
ExpenseTracker/

│
└── README.md
````

## ✨ Features

### 1. Add Expense

The user can enter:

* Expense title
* Amount
* Category
* Date

Example:

```text
Enter expense title: Book
Enter amount: 300
Enter category: Study
Enter date: 10/08/2026

Expense added successfully!
```

### 2. View Expense

Displays the stored expense:

```text
========== EXPENSE ==========
Title    : Book
Amount   : Rs.300
Category : Study
Date     : 10/08/2026
=============================
```

### 3. Modify Expense

The user can modify the existing expense details.

### 4. Delete Expense

The user can delete the existing expense.

### 5. Exit

The user can exit the application by selecting option `5`.
